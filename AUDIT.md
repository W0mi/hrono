# Аудит и правки — индекс

Проект: `index.html` — тренажёр по истории России (один файл, HTML + CSS + JS).
Проверено: структура и логика игры, CSS-слой, доступность, адаптивность, вес ассетов.
Инструменты: чтение кода, детектор Impeccable (`detect --json`), рендер в Chrome на 320/390/1280.

## Что изменено

**Медведь Хроно**

- Три кадра одного героя: главное меню — медведь с книгой «История России» (560×672 WebP), вкладка «Поиграть» — медведь с телефоном (520×780) плюс кроп головы для экранов сложности и итогов, вкладка кормления — сидящий медведь (720×720). Старые три JPEG (640×640/640×480/256×256, 133 КБ base64) удалены.
- Белый фон вырезан по-настоящему: заливка от краёв + размытие альфы + «раз-премультиплай», поэтому картинка честно прозрачная (WebP с альфой) и не даёт белой вспышки при загрузке. Приём с `mix-blend-mode:multiply` убран — он и был причиной мигания белого прямоугольника.
- Спит один и тот же персонаж, а не второй герой: состояние передаётся CSS (приглушение + «💤»), константа `BEAR_SLEEP` удалена.
- Полоска сытости получила градиент по состоянию (зелёный → золотой → красный).

**Визуальный слой**

- Токены: тёплая линия `--line`, чернильные цвета текста, `--muted` поднят до AA, две тени, единый радиус.
- Фон: слоистый градиент вместо трёхстопового «загара»; на широких экранах приложение — карточка с тенью и скруглением.
- Типографика: заголовки — антиква (Georgia), интерфейс — Segoe UI; табличные цифры у счётчиков.
- Кнопки: убран `uppercase` (ломались длинные русские подписи), мягкий градиент, глубина 4 px вместо 5–6.
- Карточки, опции, прогресс, модалки, тосты, топбар — единые состояния `hover/active/disabled`.
- `:focus-visible`, `prefers-reduced-motion`, тап-таргеты 44 px у иконочных кнопок.

**Функциональные баги (найдены аудитом)**

- Спячка: `lastDay` писался только за пройденный урок, а «дата визита» не обновлялась — медведь мог спать бесконечно. Теперь `lastVisit` пишется на каждом заходе.
- Последний вопрос урока терялся, если жизни кончились именно на нём.
- Ошибка в задании «пары» не отнимала жизнь (бесконечные попытки).
- `favIcon` с пустым `href` тянул весь документ как иконку.
- На экране урока одновременно висели два бара (общий топбар + панель урока); нижняя панель не прижималась к низу экрана.

**Доступность**

- `aria-live` у обратной связи и тоста, `role="dialog"` у модалки выхода, `aria-pressed` у звука, `aria-label` у «✕», `role="progressbar"` у прогресса.
- Карточки эпох доступны с клавиатуры (`tabindex`, Enter/Space), вложенная кнопка убрана из таб-порядка.
- Текстовые пары доведены до AA: `#e07b00 → #a04d00`, белый на голубом → `#0f7cb5…#0b6fa4`, `#d4a900 → #8a6100`, приглушённый текст → `#6f5d49`.

## Что осталось

1. Эмодзи (🔥⚡🪕🎮🌱📚) соседствуют с SVG-набором `EPICONS` — стоит перевести топбар и уровни на SVG.
2. `QUESTIONS` занимает ~127 КБ (40% файла) — кандидат на вынос в JSON с загрузкой по эпохе.
3. Три «глубины» `border-bottom` (3/4/5 px) и 7 радиусов ещё не сведены к одной шкале.
4. Контент: 45 из 48 вопросов «правда/ложь» имеют ответ «Верно» — тактика «всегда Верно» работает.
5. Дневной подарок выдаётся как побочный эффект открытия магазина.
