ИСТОРИЯ РОССИИ — ТРЕНАЖЁР ЭПОХ
==============================

Интерактивная игра-тренажёр по истории России для самостоятельного изучения:
8 эпох (от Древнерусского государства до Советского периода), в каждой —
3 уровня сложности (лёгкий / средний / высокий). Вопросы составлены по
конспекту «1.docx»: 36 тем, 5 типов заданий (выбор ответа, правда/ложь,
вставка слова, порядок событий, соединение пар).

ЭПОХИ ОТКРЫВАЮТСЯ ПО ОЧЕРЕДИ
--------------------
Сначала доступна только 1-я эпоха. Пройди в ней все три уровня — и откроется
следующая. За каждый верный ответ даётся балалаика 🪕.

ТАМАГОТМИ «ХРОНО»
-----------------
Медведь-историк Хроно: кормите его яблоками и мёдом, не пропускайте дни
(иначе уйдёт в спячку). В магазине можно купить еду и платные подсказки
(убирают неверный вариант в вопросе). Ежедневный подарок — балалайки.

КАК ЗАПУСТИТЬ
-------------
1. Откройте файл index.html двойным щелчком в любом современном браузере
   (Chrome, Firefox, Edge, Safari) — на компьютере или телефоне.
2. Интернет не нужен: весь код в одном файле, никаких зависимостей.
3. Звук включается после первого касания/клика (требование браузеров);
   кнопка 🔊/🔇 в правом верхнем углу управляет звуком.
4. Прогресс, балалайки и сытость Хроно сохраняются в самом браузере
   (localStorage). Если очистить данные сайта — прогресс начнётся заново.

СТРУКТУРА ПРОЕКТА
-----------------
index.html    — вся игра (HTML + CSS + JavaScript в одном файле).
dev-scripts/  — служебные скрипты разработки (патчи и публикация).
                Для игры НЕ НУЖНЫ; пригодятся, если захотите изменить игру:
                - patch_*.py / revert_*.py — точечные правки кода игры;
                - publish_csb.js — публикация на Codesandbox (нужен npm
                  install lz-string);
                - make_avatar.py — генерация портрета Хроно;
                - read_docx.py / check_html.py — извлечение конспекта и
                  проверка HTML.
package.json  — зависимости для публикации (только для publish_csb.js).

Онлайн-версия последней сборки: https://vzgs5g.csb.app
