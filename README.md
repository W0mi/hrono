# История России — тренажёр эпох

Интерактивный тренажёр по истории России: 8 эпох, в каждой три уровня сложности,
288 вопросов по конспекту «1.docx». Плюс тамагочи — медведь-историк Хроно,
которого нужно кормить, чтобы он не ушёл в спячку.

**Играть:** https://w0mi.github.io/Hrono/

## Что внутри

- `index.html` — вся игра: HTML, CSS и JavaScript в одном файле, без зависимостей и сборки.
- `screenshots/` — скриншоты интерфейса.
- `AUDIT.md` — разбор проекта и список правок.
- `dev-scripts/` — служебные скрипты разработки, для игры не нужны.

## Как запустить локально

Открыть `index.html` в любом современном браузере — интернет не нужен.
Прогресс, балалайки и сытость Хроно хранятся в `localStorage`.

## Механика

- Эпохи открываются по очереди: пройди все три уровня — откроется следующая.
- За верный ответ дают балалайку 🪕, за них покупается еда и подсказки.
- Хроно просыпается голодным: кормите яблоками и мёдом, заходите каждый день.
